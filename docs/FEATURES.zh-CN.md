# Filee Lite 1.12.0 功能说明

本文描述当前仓库构建出的 **Filee Lite**（版本 1.12.0）实际具备的功能，依据本仓库源码与发布脚本编写。

Filee Lite 是 Filee 的精简分支，只保留**图片与 PDF 的转换**，去掉安装程序、系统集成、联网更新和大部分附加工具。因此本文的能力清单与上游完整版 README 并不相同：完整版里的视频、办公文档、电子书、压缩包、CAD、字体、字幕、3D、地理信息等能力在 Lite 中不存在，**请以本文为准**。

---

## 1. 概览

| 项目 | 说明 |
| --- | --- |
| 版本 | 1.12.0 |
| 产品形态 | Filee Lite：单个自包含 `Filee.exe`（约 26 MB），无需安装，无需 .NET 运行时 |
| 操作系统 | Windows 10 / 11（脚本同时支持 x86、arm64 构建，默认 win-x64） |
| 界面 | Avalonia 桌面应用，简体中文 / English |
| 常驻方式 | 系统托盘 + 全局手势，单实例 |
| 核心能力 | 图片格式互转、图片→PDF、PDF→图片、PDF 拆分 / 页面范围 / 合并 |
| 转换引擎 | SkiaSharp、PDFsharp、PDFium（PDFtoImage），全部内置 |
| 网络 | 不访问网络，无遥测、无更新检查 |
| 用户数据 | `%APPDATA%\Filee`（可用 `FILEE_DATA_DIR` 改到别处） |
| 系统写入 | 不写入注册表：不注册开机启动、不注册资源管理器右键菜单 |

## 2. 快速上手

1. 双击 `Filee.exe`，程序驻留托盘，不占任务栏。
2. 在资源管理器中选中文件，按住 **Ctrl** 用鼠标左键拖动（默认手势）。
3. 光标处弹出环形工具栏（甜甜圈），把文件拖到目标扇区上松手。
4. 转换完成，输出文件默认写在**源文件旁边**；同名文件已存在时自动加 ` (2)`。

除了拖拽，还有两个入口：

- **键盘快捷键**：默认 `Ctrl + Alt + Space`，读取资源管理器中选中的文件并打开圆环。
- **主窗口首页**：把文件拖到首页的拖放区，圆环在落点打开；也可以从首页的历史记录重新打开输出文件。

从资源管理器或桌面拖拽时，Filee **始终以「复制」方式接收**文件，源文件不会被移动或删除。

## 3. 环形工具栏（甜甜圈）

### 3.1 两种出现方式

| 方式 | 行为 |
| --- | --- |
| 拖拽模式 | 按住手势修饰键拖动文件时，出现一个不可见的等待窗口；文件真正进入后才弹出圆环。没有文件时不显示。整个拖动过程有 10 秒上限。 |
| 点击模式 | 键盘快捷键、首页拖放区、命令行 `--convert` 都会直接激活圆环窗口（不需要按住鼠标）。 |

圆环打开后：

- 把文件拖到某个扇区上松手即开始转换，中心显示「拖到这里取消」。
- 点击模式下，点击扇区即开始；按 `Esc`、点击圆环外部、或开始一个新手势都会关闭。
- 圆环有进度时，`Esc` / 点击外部 / 新手势会把任务**交接给 Toast**，不会取消任务。

### 3.2 自动选择圆环

Filee 根据拖入文件的扩展名自动挑选圆环配置（profile）：

| 配置 | 适用扩展名 | 正面预设 | 背面预设 |
| --- | --- | --- | --- |
| 图片 | png、jpg、jpeg、jfif、webp、bmp、gif、ico | PNG、JPG、WEBP、PDF、BMP、ICO、JPG 70%、缩小 50% | 旋转（组）、翻转（组）、灰度、合并 PDF |
| PDF | pdf | PNG、JPG、WEBP、拆分 PDF、合并 PDF、PDF | BMP、ICO、缩小 50%、灰度 |
| 混合文件 | 兜底，不限制扩展名 | PDF、合并 PDF、PNG、JPG | WEBP、缩小 50%、灰度 |

选择规则：优先使用**第一个覆盖全部扩展名**的普通配置；没有则使用扩展名覆盖的兜底配置；再没有则使用不限扩展名的兜底配置（最后退回第一个配置）。圆环最多 12 个扇区。

### 3.3 正面与背面

- 默认按 **Tab** 翻到背面，再按一次翻回正面；也可以用**鼠标滚轮**翻转（默认开启，可在设置中关闭）。
- 翻面键可在「设置 → 快捷操作」中录制、恢复为 Tab 或清除。
- `Esc`、`Enter`、`Space`、方向键、`Backspace` 是圆环自己的按键，**不能**设为翻面键；与某个键盘快捷键冲突的键也不行。
- 背面为空时圆环不翻转，正面也不会显示翻面提示。

### 3.4 分组子环

「旋转」「翻转」是分组，不是一个直接转换：

- 指针在一个分组上停留约 160 ms，或从分组向外移动 10 px，外侧会展开子环。
- 子环最多 6 项，只包含普通转换，不能再嵌套分组。
- `Esc` / `Backspace` 先收起子环，再按一次才关闭整个圆环。
- 键盘：方向键移动高亮，`Enter` / `Space` 选中，`Esc` 退出。

### 3.5 鼠标与键盘

- 鼠标：悬停高亮扇区；中心区域用于取消。
- 键盘：方向键切换扇区，`Enter` / `Space` 执行，`Esc` 关闭，翻面键切换正反面。
- 扇区标签显示目标格式或预设名；「同格式」表示输出与源文件同格式（例如旋转、缩小）。

### 3.6 不可用扇区与失败提示

不适用的扇区会灰显，并在中心说明原因：

| 提示键 | 含义 |
| --- | --- |
| `error.unsupported_source` | 不支持此文件类型 |
| `error.no_route` | 没有引擎可以完成此转换 |
| `error.cannot_turn` | 只能旋转和翻转图片（例如把旋转预设用在 PDF 上） |

转换失败的文件会在首页的失败列表和 Toast 中给出原因；密码保护的 PDF 会失败，但失败列表可能直接显示内部键名 `error.password_protected`（该键没有中文文案，属于已知显示瑕疵）。

### 3.7 进度环

松手后圆环原地变成进度环：

- 扇区收拢，显示进度弧与百分比；最短显示 0.6 秒，避免一闪而过。
- 成功：中心出现 ✓，保持 0.9 秒后淡出。
- 失败：中心出现 !，保持 1.4 秒。
- 取消：0.2 秒内收起。
- 运行中点击环上的 **×** 可取消任务；完成后点击环可**打开输出文件夹**。
- 超过 5 秒仍未完成，任务自动交接给 Toast 继续显示。

### 3.8 Toast 通知

- 位置：屏幕右下角，多个任务向上堆叠。
- 内容：进度条、文件名、状态。
- 按钮：运行中可**取消**；失败后可**重试**；有输出时可**查看**（打开输出文件夹）；右上角 × 关闭。
- 停留时间：成功 5 秒，失败 15 秒。
- 由圆环发起且很快完成的任务只在圆环上显示 ✓，不会额外弹出 Toast。

## 4. 转换能力

### 4.1 支持的格式

**图片**

| 方向 | 格式 |
| --- | --- |
| 读取 | PNG、JPG（jpg/jpeg/jpe/jfif）、WEBP、BMP（bmp/dib）、GIF、ICO |
| 写出 | PNG、JPG、WEBP、BMP、ICO |

**PDF**

| 方向 | 支持 |
| --- | --- |
| 图片 → PDF | PNG、JPG、WEBP、BMP、GIF、ICO |
| PDF → 图片 | PNG、JPG、WEBP、BMP、ICO |
| PDF → PDF | 拆分（每页一个文件）、提取页面范围、合并多个 PDF |

其它所有格式（TIFF、AVIF、HEIC、SVG、视频、音频、Office、HWP、电子书、压缩包、CAD、字体、字幕、数据、3D、地理信息等）在 Lite 中**不可转换**。格式表里可能仍列出这些名字，但没有任何引擎提供对应的转换路径，选择了也只会得到「不支持此文件类型」或「没有引擎可以完成此转换」。

### 4.2 图片转换细节

- **EXIF 方向**：读取时先按 EXIF 方向摆正，再应用预设的旋转 / 翻转。
- **旋转**：向左 90°、向右 90°、180°。
- **翻转**：水平、垂直（在旋转之后执行）。
- **缩放**：按百分比（默认 50%）、按长边（默认 1920 px，不放大）、按宽度（默认 1200 px，不放大）。
- **灰度**：按亮度重新着色。
- **透明背景**：JPG 没有 alpha 通道，透明像素会铺上背景色（默认 `#FFFFFF`）。
- **质量**：JPG / WEBP 使用预设的 Quality（内置预设为 90 / 85 / 70；旋转翻转预设用 95 以减少重编码损失）。
- **WEBP**：默认有损；预设可切换为无损。
- **BMP**：写出 32 位 BI_RGB。
- **ICO**：写 PNG-in-ICO，可嵌入多个尺寸，默认 256/128/64/48/32/16。
- **GIF**：只读取第一帧，Lite 不能写出 GIF。
- **同格式转换**：允许（例如 JPG → JPG 只做缩小或灰度），会重新编码。
- **不生效的图片选项**：`Dpi` 只用于图片→PDF 的页面尺寸换算，不写入图片文件；`KeepMetadata`、`RemoveBackground`（及其容差、保留内部背景）、`MultiPageTiff`、`TiffCompression`、`AnimationSpeed` 在 Lite 中不被使用。

### 4.3 图片 → PDF

- 每个图片生成一页。
- 页面尺寸：
  - **适应图片**（默认）：页面尺寸等于图片尺寸；
  - **A4** / **Letter**：图片按比例居中放入，可设置页边距（毫米）；横图自动使用横向页面。
- 尺寸换算使用图片预设的 `Dpi`（未设置时按 96 DPI）。
- 嵌入方式：不透明的 JPG 源保持 JPEG（质量不低于 85，避免二次损失），其余情况以 PNG 无损嵌入。
- 图片预设中的旋转、翻转、缩放、灰度同样生效。
- 与其它图片一起选择「合并 PDF」时，每个图片先转成 PDF，再按文件顺序合并。

### 4.4 PDF → 图片

- 使用 PDFium 渲染，默认 **150 DPI**，可在预设中调整（限制 36–1200）。
- 白底渲染，包含注释与表单填充内容。
- 按页面范围输出；只有一页时不加后缀，多页时文件名追加 `_p1`、`_p2`……
- 渲染后的图片会应用图片预设：缩放、旋转、翻转、灰度、质量、格式参数。

### 4.5 PDF → PDF

- **拆分 PDF**：每一页保存为单独文件，命名 `原文件名_p1.pdf`、`_p2.pdf`……输出到 `原文件名` 子文件夹。
- **页面范围**：预设的 `PageRange` 支持 `1-3,5` 这样的写法；留空表示全部页面。设置拆分时按范围内的页面逐页输出；不拆分时把范围内的页面提取成一个 PDF。
- **合并 PDF**：把多个文件按顺序合并成一个 PDF；图片输入会先各自转成 PDF。输出以**第一个文件**命名，默认加 `_merged`。
- PDF → PDF 是**页面原样复制**，不压缩、不重排。因此：
  - 「缩小 50%」「灰度」用在 PDF 上**不会改变内容**，只是原样复制页面；
  - 「旋转」「翻转」用在 PDF 上会被判定为不可用（`error.cannot_turn`）。
- 密码保护的 PDF 无法打开，任务失败。

### 4.6 转换引擎

| 引擎 | 负责 | 说明 |
| --- | --- | --- |
| SkiaSharp | 图片 ↔ 图片 | 读写 PNG/JPG/WEBP/BMP/ICO，读取 GIF；不处理 TIFF |
| PDFsharp | 图片 → PDF、PDF → PDF、合并 PDF | 页面复制、拆分、页面范围、合并 |
| PDFium（PDFtoImage） | PDF → 图片 | 渲染页面为位图，再交给 Skia 编码 |

引擎优先级保存在设置中（默认 `skia`、`pdfium`、`pdfsharp`），Lite 没有引擎管理页面，一般无需调整。

### 4.7 Lite 不支持的相关功能

- PDF 压缩 / 减小体积（需要 ImageMagick 与 Ghostscript，Lite 已移除）。
- PDF 页面拼接成长图、裁掉页边空白。
- 多页 TIFF 输出。
- 把多个文件打包成一个压缩包。
- 去除背景、保留/移除元数据（预设模型里有字段，Lite 引擎不执行）。
- 裁剪（交互式 Crop 工具）。
- 浏览器拖放与网页下载。

## 5. 内置预设

首次运行或「恢复默认」时创建以下预设。

### 5.1 转换预设

| 预设名 | 目标 | 关键参数 | 输出文件名 |
| --- | --- | --- | --- |
| PNG | png | — | `{name}.png` |
| JPG | jpg | 质量 90 | `{name}.jpg` |
| JPG 70% | jpg | 质量 70 | `{name}_70.jpg` |
| WEBP | webp | 质量 85 | `{name}.webp` |
| BMP | bmp | — | `{name}.bmp` |
| ICO | ico | 多尺寸图标 | `{name}.ico` |
| PDF | pdf | 适应图片 | `{name}.pdf` |
| 合并 PDF | pdf | 合并成一个 | `{name}_merged.pdf` |
| 拆分 PDF | pdf | 每页一个文件 | `{name}/{name}_p1.pdf`… |
| 缩小 50% | 同格式 | 百分比缩放 50% | `{name}_50.{ext}` |
| 灰度 | 同格式 | 灰度 | `{name}_gray.{ext}` |
| 向左旋转 | 同格式 | 左转 90°，质量 95 | `{name}_left.{ext}` |
| 向右旋转 | 同格式 | 右转 90°，质量 95 | `{name}_right.{ext}` |
| 旋转 180° | 同格式 | 180°，质量 95 | `{name}_180.{ext}` |
| 水平翻转 | 同格式 | 左右镜像，质量 95 | `{name}_mirrored.{ext}` |
| 垂直翻转 | 同格式 | 上下镜像，质量 95 | `{name}_flipped.{ext}` |

「旋转」「翻转」两个分组把后五个预设收进子环。

### 5.2 默认圆环布局

- **图片**：正面 8 项（PNG、JPG、WEBP、PDF、BMP、ICO、JPG 70%、缩小 50%），背面 4 项（旋转组、翻转组、灰度、合并 PDF）。
- **PDF**：正面 6 项（PNG、JPG、WEBP、拆分 PDF、合并 PDF、PDF），背面 4 项（BMP、ICO、缩小 50%、灰度）。
- **混合文件**：正面 4 项（PDF、合并 PDF、PNG、JPG），背面 3 项（WEBP、缩小 50%、灰度）。

### 5.3 预设参数与 JSON

Lite 没有预设编辑页面，但预设以 JSON 保存在数据文件夹的 `presets.json` 中，可通过「常规 → 预设与工具栏 → 导出 / 导入」批量修改。

在 Lite 中**实际生效**的图片参数：

- `Quality`、`Resize`（`None` / `Percent` / `LongEdge` / `Width`）、`ResizePercent`、`LongEdge`、`Width`
- `Rotation`、`Flip`、`Grayscale`
- `Background`（无 alpha 的目标格式使用）
- `WebpLossless`、`IcoSizes`
- `Dpi`（仅图片 → PDF 的页面尺寸换算）

在 Lite 中**实际生效**的 PDF 参数：

- `MergeIntoSingle`、`SplitPages`、`PageRange`
- `PageSize`（`FitImage` / `A4` / `Letter`）、`MarginMm`
- `RenderDpi`（PDF → 图片）

模型里存在但 Lite 不执行：`RemoveBackground`、`BackgroundTolerance`、`KeepEnclosedBackground`、`KeepMetadata`、`KeepColorProfile`、`MultiPageTiff`、`TiffCompression`、`AnimationSpeed`、`CombinePages`、`TrimPageMargins`、`SplitTallImage`、`Compression`、`CompressWithGhostscript`，以及整套 `Document` / `Media` / `Archive` / `Trace` 选项。

### 5.4 导出、导入与恢复默认

- **导出**：把预设与圆环配置写成一个 JSON 包（`PresetBundle`）。
- **导入**：同 ID 的项替换，新 ID 的项追加。
- **恢复默认**：把所有预设和圆环配置恢复为内置状态，操作前会确认。

## 6. 输出与命名

### 6.1 保存位置

- 预设的保存位置可以是：源文件旁、源文件夹下的子文件夹（默认 `converted`）、固定文件夹。
- 「常规 → 默认保存位置」只影响**保存位置为「默认」的预设**；单独设置过位置的预设不受影响。
- 内置的「拆分 PDF」固定输出到 `{name}` 子文件夹，不受全局默认位置影响。

### 6.2 文件名

- 默认使用源文件名。
- 支持的占位符：`{name}`（去扩展名的文件名）、`{ext}`（原扩展名）、`{preset}`（预设名）、`{date}`（yyyyMMdd）、`{time}`（HHmmss）、`{index}`（序号）。
- 非法字符（`< > : " / \ | ? *` 及控制字符）替换为 `_`，结尾的点和空格会被去掉。
- 没有可用名称时回退到源文件名。

### 6.3 重名与覆盖

- 默认策略：自动追加 ` (2)`、` (3)`……
- 也可设置 `Overwrite`（覆盖已存在的输出）或 `Skip`（跳过，界面提示「已跳过（文件已存在）」）。
- **源文件永远不会被覆盖**，无论选择哪种策略。
- 多页输出与拆分使用 `_pN` 后缀；合并在一个批次内保留输出名，避免互相覆盖。

### 6.4 日期

「常规 → 所有转换都保留原文件日期」开启后，输出文件沿用源文件的创建时间和修改时间；关闭时由每个预设自己的「保留原文件日期」决定。

## 7. 主窗口

主窗口左侧只有三个页面：**首页、常规、快捷操作**。打开主窗口不会中断托盘与手势；关闭行为见 7.2。

### 7.1 首页

- **拖放区**：接受本地文件（快捷方式会解析到目标）；松开后圆环在落点打开。只接受本地文件，不接受浏览器拖出的内容；文件夹可以拖入，但 Lite 没有可用的文件夹预设，会被判为不支持。
- **最近的转换**：列出最近 40 条记录；搜索框可匹配预设名或源文件名（忽略大小写），搜索范围是**全部历史**。
- **缩略图**：图片输出显示缩略图（后台加载，限制 64 MB / 4096×4096 像素）；PDF 等显示格式徽章。
- **操作**：打开文件、打开方式（仅 Windows）、打开文件夹。
- **失败列表**：显示失败文件、原因，并可按原预设重试。
- **清除**：清空转换记录。
- **管理员警告**：Filee 以管理员身份运行时，无法从资源管理器拖放、也无法读取资源管理器选中项，首页会提示以非管理员身份重启。

### 7.2 常规

| 设置 | 说明 |
| --- | --- |
| 语言 | 跟随系统 / English / 简体中文；「跟随系统」在中文系统上用简体中文，否则用英文 |
| 登录时启动 Filee | **Lite 中不生效**：单 exe 不写入自启动项，开关只保存偏好 |
| 在程序坞 / 菜单栏中显示 | 仅 macOS 相关；Windows 上不显示 |
| 关闭窗口时 | 每次询问 / 在托盘中继续运行 / 退出 Filee；询问对话框可勾选「不再询问」 |
| 资源管理器右键菜单 | **Lite 中不生效**：不写入注册表，右键菜单不会出现 |
| 默认保存位置 | 源文件旁 / 子文件夹（默认 `converted`）/ 固定文件夹，以及「所有转换都保留原文件日期」 |
| 转换记录 | 不保留 / 保留，最多 50–2000 条（默认 200 条），可清除 |
| 预设与工具栏 | 导出、导入、恢复默认 |
| 设置文件夹 | 显示数据目录并可打开 |
| 版本号 | 显示在主窗口左下角（`版本 1.12.0`） |

### 7.3 快捷操作

- 手势列表：添加、删除、启用/停用，可保留任意多个。
- 手势类型：
  - **修饰键 + 拖动文件**（Drag）：按住修饰键拖动文件；
  - **修饰键 + 长按**（Hold）：按住修饰键和鼠标键不动，达到时长后触发，读取资源管理器选中项；
  - **键盘快捷键（选中的文件）**（KeyChord）：修饰键 + 一个按键，读取选中项。
- 修饰键：Ctrl / Alt / Shift / Meta（Windows 键），可组合。
- 鼠标键：无、左键、右键、中键、后退（X1）、前进（X2）。
- 拖动距离：0–200 逻辑像素，0 表示系统默认。
- 按住时间：150–3000 毫秒，默认 450。
- 生效范围：文件管理器和桌面 / 所有位置。
- 排除应用：输入进程名后回车，或从正在运行的应用中选择；指针位于这些应用上时不触发。
- 翻面键：录制、恢复为 Tab、清除；以及「用鼠标滚轮翻转圆环」开关。
- 状态区：显示全局输入检测是否运行、失败原因，并提供「重试手势」。

默认手势（Windows）：

| 手势 | 配置 |
| --- | --- |
| 修饰键 + 拖动文件 | Ctrl + 鼠标左键，范围：文件管理器和桌面 |
| 键盘快捷键 | Ctrl + Alt + Space |

## 8. 托盘、单实例与命令行

### 8.1 托盘

- 右键菜单：打开 Filee、暂停快捷操作 / 恢复快捷操作、退出。
- 单击托盘图标：打开主窗口。
- 悬停提示：显示当前拖拽手势的修饰键（如「Filee：按住 Ctrl 拖动文件」，没有拖拽手势时显示 `—`）；暂停时显示「快捷操作已暂停」。
- 暂停只停用手势，首页、拖放区和命令行仍可转换。

### 8.2 单实例

- 同时只运行一个 Filee；再次启动会把参数转发给已运行的实例。转发失败（对方无响应或以管理员身份运行）时提示。
- 已运行的实例收到无参数启动请求时，直接显示主窗口。
- `--convert` 会在 350 毫秒内收集文件后统一打开圆环（资源管理器可能为每个选中文件启动一个进程）。

### 8.3 命令行

| 命令 | 行为 |
| --- | --- |
| `Filee.exe` | 打开主窗口 |
| `Filee.exe --background` | 只在托盘启动，不显示窗口 |
| `Filee.exe --settings` | 打开主窗口 |
| `Filee.exe --convert a b ...` | 为这些文件打开圆环 |
| `Filee.exe --convert-list <file>` | 与 `--convert` 相同，路径来自 UTF-8 文本文件（每行一个）；使用后删除该临时文件 |
| `Filee.exe --quit` | 请求已运行的 Filee 退出，并等待其结束 |

`--convert-list` 只删除位于临时目录、文件名以 `Filee-convert-` 开头且以 `.txt` 结尾的列表文件，避免误删。

## 9. 语言与外观

- **语言**：仅 English 与简体中文。`auto` 时中文系统使用 `zh-CN`，其它系统使用英文。语言切换即时生效，主窗口页面会重建以更新文案。
- **明暗模式**：跟随系统（Lite 没有主题页面，不能在界面中强制切换）。
- **强调色与圆角**：默认强调色 `#7F77DD`，基础圆角 16 px，Lite 界面中不可修改。
- **自定义配色**：在数据文件夹放置 `theme.json`，可按明暗两套覆盖页面、文字、状态色等颜色；缺失的键沿用默认值。
- **动效**：默认跟随系统的「减少动态效果」设置；可在 `settings.json` 的 `Theme.ReduceMotion` 中覆盖，界面没有开关。
- **圆环外观**：外半径 150 px、内圈比例 0.42、不透明度 0.96，均为默认值，Lite 没有环形工具栏页面可调。

## 10. 数据、日志与隐私

### 10.1 数据文件夹

默认 `%APPDATA%\Filee`，包含：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 全部设置（语言、手势、输出、历史上限、翻面键等），带 `SchemaVersion` |
| `presets.json` | 预设 |
| `profiles.json` | 圆环配置（正面/背面、扩展名） |
| `history.json` | 转换历史 |
| `theme.json` | 可选，自定义配色 |
| `logs\filee-yyyyMMdd.log` | 日志，保留 7 天 |

- 写入采用原子替换；损坏的 JSON 会被复制为 `*.broken` 并以默认值重建，避免直接丢失原文件。
- 设置 `FILEE_DATA_DIR` 环境变量可把数据目录移到别处；这样启动的实例拥有独立的单实例与托盘状态，也不会注册系统集成。
- 转换过程中的中间文件放在 `%TEMP%\Filee\<jobId>`，任务结束（含失败、取消）后删除。

### 10.2 隐私

- 不发起任何网络请求，没有 HttpClient、没有遥测、没有更新检查。
- 只读取被拖入或选中的文件，只写入输出目录、数据目录和临时目录。
- 「打开方式」调用系统默认程序；「打开文件夹」调用资源管理器。

## 11. 部署、升级与卸载

### 11.1 构建

发布脚本：`build/build-lite.ps1`

| 参数 | 说明 |
| --- | --- |
| `-OutputDir` | 输出目录，默认仓库根目录的 `Releases-lite` |
| `-Runtime` | `win-x64`（默认）、`win-x86`、`win-arm64` |
| `-Version` | 覆盖版本号，默认取 `Directory.Build.props`（1.12.0） |
| `-Zip` | 额外生成 zip（含 LICENSE）与 SHA256 校验文件 |
| `-NoTrim` | 关闭 IL 裁剪，体积约增加 25 MB；发布版启动或拖拽异常时使用 |

发布参数：`PublishSingleFile`、`EnableCompressionInSingleFile`、`PublishTrimmed`、`IncludeNativeLibrariesForSelfExtract`，并带 `-p:FileeRelease=false`（因此不做系统注册）。

> 注：`docs/LITE.md` 把产物路径写作 `build/Releases-lite/`，与脚本默认值（仓库根目录下的 `Releases-lite/`）不一致，请以脚本为准。当前已构建的产物在 `Releases-lite/Filee-Lite-1.12.0-win-x64/Filee.exe`。

### 11.2 安装与运行

无需安装：把 `Filee.exe` 放到任意文件夹（桌面、U 盘、下载目录均可），双击运行。

- 首次启动会触发 SmartScreen 提示（未签名）：选择「更多信息」→「仍要运行」。
- 首次启动稍慢：单文件内的 Skia / PDFium 原生库会解压到临时目录，之后恢复正常。

### 11.3 升级与卸载

- **升级**：退出 Filee，用新版本 `Filee.exe` 覆盖旧文件即可；设置、预设、历史都在数据文件夹中保留。
- **卸载**：退出 Filee，删除 `Filee.exe`；可选删除 `%APPDATA%\Filee`。系统里没有注册表项、服务或自启动项需要清理。
- **没有自动更新**：Lite 不检查版本、不下载更新。

## 12. Lite 的边界与已知限制

### 12.1 与完整版相比缺少的界面/能力

- 没有「更新 / What's new」、引擎下载与管理、监视文件夹（自动转换文件夹）。
- 没有「环形工具栏」「预设」「主题」「转换引擎」「关于」页面；圆环大小、内圈、不透明度、强调色、明暗模式、减少动效均无界面开关。
- 没有预设编辑器和工具栏编辑器；只能用默认布局，或通过导出的 JSON 修改后导入。
- 没有浏览器拖放与网页下载。
- 没有裁剪工具。
- 只有 English 与简体中文两种语言。
- 只发布 Windows（脚本支持 x86 / x64 / arm64），不提供 macOS / Linux 打包。

### 12.2 能力上的硬限制

- 只能读 PNG/JPG/WEBP/BMP/GIF/ICO，只能写 PNG/JPG/WEBP/BMP/ICO；**没有 GIF、TIFF、AVIF、HEIC 输出**。
- GIF 只取第一帧，动图会变成静态图。
- PDF → PDF 不压缩；「缩小 50%」「灰度」对 PDF 只是原样复制。
- 旋转 / 翻转不能用于 PDF。
- 密码保护的 PDF 无法读取，失败提示可能显示内部键名。
- 不支持多页 TIFF、归档合包、PDF 长图拼接。
- 从浏览器拖出的内容不会被接收；必须先是本地文件。
- 以管理员身份运行时，资源管理器拖放和选中项读取都不可用（Windows 的权限隔离）。

### 12.3 系统集成说明

- 「登录时启动 Filee」「资源管理器右键菜单」两个开关在界面上存在，但 Lite 发布时不注册任何系统项，**切换不会生效**。
- Windows 11 顶层右键菜单需要随包分发的资源管理器组件（DLL 与 MSIX 包），单 exe 未包含，因此该选项不显示。
- 托盘、手势、单实例不需要系统集成即可工作。

### 12.4 其它行为

- 拖拽始终以「复制」语义接收，源文件不会被移走。
- 源文件永远不会被输出覆盖。
- 单实例：需要同时运行两个独立实例时，用不同的 `FILEE_DATA_DIR` 启动。
- 转换按任务顺序排队（同一时间一个任务），任务内的文件按 CPU 核心数并行。
